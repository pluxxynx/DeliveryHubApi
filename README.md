# Delivery Hub
Проверка: `GET http://127.0.0.1:5081/health`.
## Маршруты

| Метод | Маршрут | Результат |
|---|---|---|
| POST | /api/delivery/calculate | Выбранный перевозчик, цена, срок, надёжность, альтернативы |
| GET | /api/delivery/carriers?periodDays=30&city=Казань | Статистика учебных выполненных отправлений |
| POST | /api/batch/optimize | Сформированные и сохранённые партии, общая экономия |
| GET | /api/batch | Последние 5000 сохранённых партий |

## Бизнес логика
Учебные тарифы: СДЭК 300 + 60 руб./кг, 3 дня, надёжность 0,97; Boxberry 250 + 50 руб./кг, 4 дня, 0,95; Почта России 200 + 40 руб./кг, 6 дней, 0,92. Это демонстрационные значения, не реальные предложения компаний.

Оплачиваемый вес — максимум физического веса и L×W×H/5000. Для одного города цена без страховки умножается на 0,8, срок уменьшается на день (минимум 1). Страховая составляющая — 0,5% объявленной ценности.

Скоринг точно следует формуле работы 1: wPrice/price + wDays/days + wReliability×reliability. Веса standard = 0,4/0,3/0,3; express = 0,1/0,8/0,1; economy = 0,8/0,1/0,1. Из-за разных масштабов величин приоритет economy не гарантирует выбор минимальной цены: это ограничение исходной формулы.

Группировка: сортировка внутри города по готовности; каждая группа ограничена временем самого раннего заказа + maxWaitHours. Учебный групповой тариф 200 + 40×суммарный вес. Экономия равна устранённым фиксированным платежам: 200×(число заказов − 1). Нулевое окно объединяет только одновременные заказы. Повторный POST создаёт новые партии; идемпотентность и многопользовательский учёт не реализованы.

Статистика использует воспроизводимый набор событий за 90 дней с городами Москва/Казань. Источник помечен `educational-fixtures`; он не является фактической статистикой перевозчиков. Неизвестный город даёт нулевое число заказов, доли null.

Хранение партий — атомарная замена JSON-файла, синхронизация потоков в одном процессе. Для учебного приложения используется один экземпляр. Для промышленной эксплуатации потребуются БД, аутентификация, квоты, реальная интеграция перевозчиков. В публичный учебный API не следует отправлять персональные данные.
